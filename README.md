# webclass-deadline-calendar

## このプロジェクトは何か

大学（福知山公立大学）のWebClassから課題の締め切りを毎日0時に自動で取得し、Googleカレンダーの専用カレンダーに登録するPythonプログラムです。

- 大学ポータル（CampusPlan）にログインし、WebClassの「課題実施状況一覧（ダッシュボード）」からCSVをダウンロードします
- 締め切りがある教材を、締め切り時刻の予定（タイトル：`コース名 課題`）として登録し、1時間前に通知します
- 自分のWindows PCで、タスクスケジューラから毎日0時に実行します

詳しい仕様は [docs/計画書.md](docs/計画書.md) にあります。
